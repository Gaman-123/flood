# Paper build

`main.tex` — full IEEE-format manuscript draft. Every number in it traces to a
committed artifact in `data/processed/` or `web_assets/`; none are placeholders.

```bash
brew install tectonic          # or any pdflatex/IEEEtran toolchain
tectonic main.tex               # -> main.pdf
```

Regenerating figures after a pipeline change:

```bash
cd ../.. && source .venv/bin/activate
python3 scripts/benchmark_routing.py     # data/processed/routing_benchmark.json
python3 scripts/make_paper_figures.py    # paper/figures/*.pdf
cd paper && tectonic main.tex
```

`figures/` holds only the 8 PDF figures referenced by `main.tex`, generated by
`scripts/make_paper_figures.py` from real pipeline output — no synthetic data.
